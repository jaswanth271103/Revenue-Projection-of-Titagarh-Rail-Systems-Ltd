🧮 Calculation Formula Logic

Every major line item uses clear formulas such as:

Passenger Revenue = Sum of all Passenger Sub-Segments
Total Revenue = Freight + Passenger
Price Per Unit = Previous_Year * Growth_Rate
Capacity = Previous_Year + Increment
Utilized Capacity = Previous_Year + Increment
Total Order Value = Price Per Unit * Utilized Capacity


All formulas are documented in the “CALCULATION FORMULA” column for transparency.
